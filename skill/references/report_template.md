# 报告模板（`report.md`）

`[M1, p.N]` 指核查表条目与页码。总长建议 1500–3500 字（中文）；配置总表可以很长，不计入。

```markdown
# 《<论文标题>》复现配置核查：<复现目标，一句话>

> 材料：<文件名>，<页数> 页（正文 x 页 / 附录 y 页），提取状态 <ok/degraded>；
> 核查表 <行数> 行覆盖 26/26 项：reported a / partial b / not_reported c / conflicting d / not_applicable e / not_in_material f；门禁检查 problems = 0。

## 0. 结论先行
- 复现就绪度：可直接复现 / 补齐 n 项后可复现 / 关键设置缺失，难以复现 / 材料不完整，无法判定
- 阻断复现的前 3 项（各带 [ID, p.N] 或"未报告"及已查页）
- 第一步做什么

## 1. 要复现的目标
主结果数字及其模型、基准、变体、样本量 [T1, p.N]；关键消融告诉我们哪个设置最不能错 [T2, p.N]。

## 2. 配置总表（26 项）
| ID | 项目 | 状态 | 论文给出的值 | 出处 | 复现还缺什么 | 影响 |
按清单顺序列全部行（多值项拆行）。

## 3. 复现阻断清单（impact=high 且非 reported）
| 优先级 | ID | 缺什么 | 去哪补（查找建议） | 补不到时的替代取值（推断：理由） |

## 4. 冲突与易错点
原文前后不一致、摘要和正文表格不一致、容易张冠李戴的数字（不同模型/变体/子集）。各带两处出处。

## 5. 对照我的条件（有用户约束时）
| 我的条件 | 论文设置 | 出处 | 差异对复现的影响 |

## 6. 最小复现方案
子集与样本量、对照、步骤、成功阈值（容差及依据）、预算估计（只用原文给出的成本数字，推断要标明）。

## 7. 事实 / 推断 / 未报告
- 原文事实：……[ID, p.N]
- 推断：……（依据）
- 未报告：……（已查页，查找建议）

## 8. 自查
门禁结果；质量检查清单逐项结果；本次未完成的步骤。
```
